# SDS/GHS and regulatory data portfolio

Hi, I'm Avirat. My day job is regulatory data: safety data sheets, GHS classification, chemical master data, and the Power BI reports that sit on top of all of it. This repo is where I keep side projects that use public data to answer the kind of questions I deal with at work, usually "what does this regulation actually mean in numbers?"

Each project lives in its own folder with its own README, data, scripts and dashboard.

## Projects

| Project | What it looks at | Tools |
|---|---|---|
| [Methane and F-gas emissions vs EU rules](project-L-methane-fgas/) | How much methane and F-gas US facilities report, where it is heading to 2030, and how exposed US LNG exports are to the new EU Methane Regulation | Python (pandas), Power BI, DAX |

More to come.
